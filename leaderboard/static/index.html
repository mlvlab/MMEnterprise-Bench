Score locally, then upload the metrics file

The official scorer runs on your machine with your own judge API key. The leaderboard never calls an LLM; it only accepts the aggregate file the scorer writes.

  1. 1

    Install the package and download the benchmark

    pip install git+https://github.com/mlvlab/MMEnterprise-Bench
mmeb download
  2. 2

    Run your agent

    Write predictions.jsonl with one {"id": ..., "answer": ...} line per question. retrieved_unit_ids is optional and enables Evidence Recall for your own retrieval.

  3. 3

    Score with the official protocol

    mmeb score predictions.jsonl --output outputs/my_agent

    Needs OPENAI_API_KEY; the default judge is gpt-5.6-luna.

What to upload

  • requiredoutputs/my_agent/metrics.json as written by mmeb score (unmodified, full benchmark, fresh judge run).
  • optionalpredictions.jsonl for audit (recommended; up to 25 MB).
  • formModel name, organization, link, contact e-mail (kept private), retrieval setting, judge model.

Review: every upload lands in a private queue and is listed after maintainer approval. You receive a receipt id on submission.

  • BenchmarkMMEnterprise-Bench asks 1,613 questions over multimodal records of 30 simulated collaboration projects whose documents, slides, tables and messages are revised and contradicted over time. Eight tasks in three categories: Evidence Reasoning (1,102), Conflict Resolution (424) and Unanswerability (87).
  • ScoringAgents answer from the released top-k retrieval (2B or 8B retriever; k = 10, 50, 100), their own retrieval or the full workspace. mmeb score judges each answer with an LLM against the gold answer; accuracy is over all 1,613 questions and missing predictions count as incorrect.
  • ModerationScores are self-reported and moderated: contributors run the scorer themselves and upload its metrics.json; the file is checked for structural consistency with a fresh full-benchmark run and listed only after a maintainer approves it.
